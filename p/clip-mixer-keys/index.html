Stream Deck keys

Clip Mixer Keys

Icon pack In development

15 pixel-art keys for video editing: fetch, cut on the beat, duck the music, voice lines, render and export.

What it does

  • Fetch clip, library, plan edit, on the beat, cut, timeline, live edit, duck music, voice line, clean voice, check the facts, story video, render, export and frame grab.
  • Works with any editor that takes a shortcut: set the key's action, then pick the icon.

You need

  • Elgato Stream Deck app 7 or later
  • Any Stream Deck

Set it up

In development. Coming to Elgato Marketplace.

  1. Double-click the .streamDeckIconPack file. Stream Deck installs the pack.
  2. Click a key's image in Stream Deck, choose Clip Mixer Keys, and pick the icon.
