Universal Repo Sync

iCUE widget In development

Every repo, every machine, always in step. One tap pulls what is new and pushes what is yours.

Start on your desktop, pick up on your laptop, never hit a merge mess. Universal Repo Sync watches every Git repo on this PC, shows which ones are ahead of or behind GitHub, and brings each one level with a single tap. GitHub is the meeting point, so every device that syncs sees the same code.

Sizes

Every slot on the Xeneon Edge, smallest first, drawn to scale. Pick the one that fits your layout.

What it does

  • One Sync key per repo. The arrows show the job: up for commits to push, down for commits to pull.
  • Safe by design: pulls fast-forward only, never force-pushes, never makes a commit for you. If a repo needs a real merge, it tells you instead of guessing.
  • At a glance: how many repos have uncommitted files, commits waiting to go up, and commits waiting to come down.
  • Each repo shows its last commit and how long ago, busiest first.
  • Tap a repo to open it in VS Code or GitHub Desktop.

You need

  • Corsair Xeneon Edge
  • iCUE 5.52 or later
  • Windows
  • Git
  • The Session HQ mod

Set it up

  1. Open iCUE and select the Xeneon Edge.
  2. Open the widgets section and press the plus button.
  3. Pick the .icuewidget file you downloaded, or install it straight from Elgato Marketplace inside iCUE once it is listed there.
  4. Drag the widget into a slot. Hold it to open its settings: colours, transparency and what it shows.

Permissions

iCUE asks you to approve these when you install. Here is what each one is for. Everything stays on this PC unless a line says otherwise.

Read one status file <Home>/.session-hq-status.json
Reads the file Session HQ writes with your usage, chats and repo states. Why: It is where the numbers come from. Nothing else in your home folder is read.
File watcher iCUE File System plugin
Gets told the moment that file changes. Why: Updates land instantly instead of on a timer, with less work for your PC.
Local helper app localhost:13509
Talks to a small helper app on this PC. It answers only widgets on this PC and never opens anything to the internet. Why: Runs the Sync for the repo you tapped: git pull (fast-forward only), then git push to that repo's own remote. Never a force push, never a commit, and only repos in your GitHub folder. Swipe between Edge pages even when your finger starts on this widget. iCUE alone only swipes from the gaps between widgets.
Open links iCUE URL plugin
Opens a link or an app when you tap. Why: Opens a repo in VS Code or GitHub Desktop, and starts the helper app if it is not running, so the widget fixes itself.
