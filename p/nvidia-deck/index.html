NVIDIA Deck

iCUE widget In development

Ten touch keys for the NVIDIA app, with live FPS, CPU, GPU and memory beside them.

What it does

  • Save replay, record, screenshot, instant replay, performance overlay, vibrance, highlights, clip library and overlay.
  • Keys light up when a feature is on.
  • Live FPS of the game in front, big and in the accent colour, red under 30.
  • Large sizes add CPU, GPU and temperature, RAM, VRAM, storage and how much space your clips take.
  • Shows the game that is running.

You need

  • Corsair Xeneon Edge
  • iCUE 5.52 or later
  • Windows
  • NVIDIA app
  • A small helper that runs on your PC (included)

Set it up

  1. Open iCUE and select the Xeneon Edge.
  2. Open the widgets section and press the plus button.
  3. Pick the .icuewidget file you downloaded, or install it straight from Elgato Marketplace inside iCUE once it is listed there.
  4. Drag the widget into a slot. Hold it to open its settings: colours, transparency and what it shows.

Permissions

iCUE asks you to approve these when you install. Here is what each one is for. Everything stays on this PC unless a line says otherwise.

FPS plugin iCUE FPS plugin
Reads the frame rate and name of the app in front, measured by iCUE. Why: Shows your FPS live without running another overlay.
Local helper app localhost:13509
Talks to a small helper app on this PC. It answers only widgets on this PC and never opens anything to the internet. Why: Passes your taps to the NVIDIA app (save replay, record, overlay) and reads CPU, GPU and memory stats. iCUE widgets cannot reach the NVIDIA app directly, so the helper relays for them. Swipe between Edge pages even when your finger starts on this widget. iCUE alone only swipes from the gaps between widgets.
Open links iCUE URL plugin
Opens a link or an app when you tap. Why: Starts the helper app if it is not running, so the widget fixes itself.
