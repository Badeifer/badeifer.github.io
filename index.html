Toolbox

What you need to run these projects, plus tools worth having. No sponsored or affiliate links.

Hardware

  • Corsair Xeneon EdgeThe 14.5 inch touchscreen the iCUE widgets are made for.
  • Elgato Stream DeckRuns the Stream Deck plugins. Any model with keys works.
  • NVIDIA GeForce RTX graphics cardNeeded for the NVIDIA Deck widget and RTX Remix.

Required apps

  • iCUEInstalls and runs the Xeneon Edge widgets.
  • Stream Deck appInstalls and runs the Stream Deck plugins.
  • ObsidianThe notes app Agent Keep, Pixel Keep and Task Pet run in.
  • NVIDIA AppInstant replay, recording and the overlay that NVIDIA Deck controls.
  • Claude CodeNeeded for Session HQ and the Claude usage widget.

Claude Code add-ons

  • ImpeccableDesign reviews and polish passes for anything with a UI.
  • frontend-designPicks a real design direction before Claude builds a UI.
  • Windows-MCPLets Claude open and drive Windows apps.
  • NVIDIA App MCPLets Claude save replays, take screenshots and toggle the overlay.

Useful utilities

  • RTX RemixRemaster classic games with path tracing and new textures.
  • VentoyOne USB stick that boots any number of ISOs.
  • cobaltClean video and audio downloads, no ads.
  • MeshyAI-generated 3D models to start a print from.
  • PowerShell 7A modern shell for scripting Windows.
  • uvInstalls Python and its packages in seconds.
  • GitVersion control for any project.
